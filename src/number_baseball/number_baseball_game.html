숫자 야구

숨겨진 숫자를 맞혀 보세요. 몇 번 만에 성공할 수 있을까요?

  • 서로 다른 숫자로 이루어진 정답을 맞히는 게임입니다.
  • 숫자와 위치가 모두 맞으면 Strike입니다.
  • 숫자는 맞지만 위치가 다르면 Ball입니다.
  • 맞는 숫자가 하나도 없으면 0 Strike, 0 Ball로 표시됩니다.
  • 같은 숫자는 두 번 사용할 수 없고, 첫 번째 숫자는 0이 될 수 없습니다.
예: 정답 427 · 입력 472 → 1 Strike, 2 Ball
